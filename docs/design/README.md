# Design Documents

These are the original design documents created during Open Brain's development. They capture the initial vision, architecture decisions, and implementation plans.

- **SPEC.md** - Product specification and requirements
- **ARCHITECTURE.md** - System architecture and technical design
- **IMPLEMENTATION_PLAN.md** - Phased implementation roadmap
- **FRONTEND_DESIGN.md** - Frontend design system and component specs
- **FRONTEND_IMPLEMENTATION.md** - Frontend implementation details
- **OpenBrainUX.md** - UX research and interaction design
- **plans/** - Ad-hoc design explorations
